Nazewnictwo branchy

- Zgodnie ze wzorem Stolica-Imie_Nazwisko.

Tworzenie issue

- Opisz dokładnie problem lub propozycję funkcjonalności.
- Użyj szablonu, jeśli jest dostępny.
- Możesz przypisać się do zadania, które chcesz zrealizować.

Pull Request (PR)

- Nazwij PR zgodnie z jego celem.
- Przed utworzeniem PR:
  - Zaktualizuj swoją gałąź względem `main` (lub innej głównej).
  - Upewnij się, że testy przechodzą.
- Czekaj na zatwierdzenie przez co najmniej jednego reviewera.
